# Icône Chud Converter (conversion de fichiers)

Même style que les icônes Chud : un document doré au visage grognon et à lunettes, le fichier d'origine en bleu derrière, et deux flèches dorées en boucle pour la conversion. Dessin vectoriel pur, sans image intégrée ni police. Fond transparent, sauf les tuiles à fond cyan `#38d6ff`.

| Fichier | Usage |
|---|---|
| `svg/logo-small.svg` | Fichier maître, 32 px et plus (écran « À propos », splash) |
| `svg/logo-tiny.svg` | Version épurée pour 16 à 24 px |
| `icon.ico` | Windows, de 16 à 256 px |
| `icon.icns` | macOS, de 16 à 1024 px |
| `png/icon-N.png` | PNG transparents de 16 à 1024 px (Linux : `icon-256.png` ou `icon-512.png` dans le fichier `.desktop`) |
| `svg/icon-macos.svg`, `store/icon-macos-1024.png` | Tuile macOS à fond cyan |
| `svg/icon-square.svg`, `store/icon-square-1024.png`, `store/apple-touch-icon.png` | Carré plein à fond cyan |
| `favicon.svg` | Favicon web |

Couleurs : marine `#011128`, bleu `#123f7d`, bleu clair `#2c639f`, or `#f9c83a`, or foncé `#d9a02c`, cyan `#38d6ff`.

Consigne pour Claude Code : « Le dossier `chud-convert-icon/` contient l'icône de l'application. Lis son `README.md` et branche-la partout : exécutable et fenêtre (`icon.ico`, `icon.icns`, `png/`), barre des tâches, raccourci Linux, et écran « À propos » avec `svg/logo-small.svg`. Ne modifie pas les fichiers. »
